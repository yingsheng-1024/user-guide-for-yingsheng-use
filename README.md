# 应声使用指南

适用版本：0.4.6 · 64 位 Windows / Apple 芯片 Mac

## 使用前准备

- 使用小鹅云账号：店铺需先开通 **小鹅云 SDK 权限**，并准备小鹅云配置信息和用户 ID。
- 使用账号密码登录：店铺需开启 **浏览器访问** 和 **手机号密码登录**。配置路径：**B 端管理台 → 设置 → 店铺设置 → 登录方式配置**。

直播现场临时发评论用「实时互动」；按设定时间发送用「评论计划」。下图均为演示画面，弹窗图放在完整页面中展示；画面中的信息不是真实业务数据。

## 1. 安装并授权

Windows 双击安装包；Mac 打开安装包，把应声拖入「应用程序」。首次打开后，把设备申请码发给提供方，收到许可证后导入。

![完整授权页面，设备申请码和导入入口](images/01-license.png)

显示「授权有效」后进入工作空间。续期时直接导入新许可证。

## 2. 添加店铺与直播

进入「店铺与直播」，先填店铺编号，再填直播编号。名称会自动补全，也可修改。

![店铺与直播完整页面，显示店铺、配置和直播列表](images/02-settings.png)

![完整页面中的添加店铺窗口](images/03-add-shop.png)

![完整页面中的添加直播窗口](images/04-add-room.png)

使用小鹅云账号时，在这里填入小鹅云提供的配置信息，并选择一场正常的直播用于获取登录状态。只用手机号和密码时可跳过。

![完整页面中的小鹅云配置窗口](images/05-cloud-config.png)

## 3. 添加账号

在「账号管理」选择登录方式。账号密码方式可逐个添加，也可用下载的表格模板批量导入；小鹅云方式每行填一个用户编号。保存后会自动获取登录状态。

![账号管理完整页面，显示两种登录方式和状态](images/06-accounts.png)

![完整页面中的账号密码添加窗口](images/07-add-password.png)

![完整页面中的小鹅云账号添加窗口](images/08-add-cloud.png)

发送前确认账号显示 **登录有效**。登录失败时查看或下载「账号日志」。

![完整页面中的账号管理日志窗口](images/17-account-log.png)

## 4. 实时互动

先建用户组；使用随机内容时再建内容组。核对店铺与直播，选好内容和发送间隔，预览无误后确认发送。

![完整页面中的添加用户组窗口](images/09-user-group.png)

![完整页面中的添加内容组窗口](images/10-content-group.png)

「统一内容」让每人发送同一句；「随机内容」为每人随机选一句，可以重复。

![实时互动完整页面，统一内容和本轮结果](images/11-interaction.png)

![实时互动完整页面，随机内容和本轮结果](images/12-random.png)

右侧可查看结果，出现问题时下载本轮日志。已发出的评论无法撤回。

## 5. 评论计划

选择直播，下载评论表格。按模板每行填写一个账号编号、北京时间和评论。导入后核对内容；需要时统一调整时间，再启动发送。

![评论计划完整页面，计划列表与评论明细](images/13-plans.png)

![完整页面中的导入计划窗口](images/14-import-plan.png)

![完整页面中的统一调整时间窗口](images/15-shift-time.png)

「离线模拟」不会发出评论。计划的「日志」可查看和下载最近一次执行记录。

![完整页面中的计划执行日志窗口](images/16-plan-log.png)

## 遇到问题

账号异常下载「账号日志」；评论异常下载对应的互动或计划日志，并记下发生时间与报错。不要发送账号密码或完整数据备份。

升级前先退出应声。正常覆盖安装会保留原有数据和许可证。
